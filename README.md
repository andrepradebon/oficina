# Oficina · relatos e ordens de serviço

App para celular (instalável, funciona sem internet) usado pelos encarregados, mecânicos e pela oficina para relatar problemas nas máquinas e controlar as ordens de serviço.

- Os dados ficam numa planilha Google da empresa, não neste repositório.
- `config.js` guarda o endereço da planilha (App da Web do Apps Script, termina em `/exec`).
- Ao mudar qualquer arquivo, aumente `VERSAO` em `sw.js` para os celulares baixarem a versão nova.
